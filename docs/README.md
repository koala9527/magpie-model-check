## 看进度时记住三个区别

- **目标**：希望产品完成后的样子，还需要开发。
- **已验证**：已经实际运行过的测试，只对记录中的条件成立。
- **待验证**：尚未试过，或试过后仍没有解决，不能当成已完成。

本轮主改造已经落地：测试服务、SQLite 历史、渠道签章、参考实验审核、预算和中文页面均已实现，并已通过本机 Magpie 测试。测试只证明软件处理合成夹具的行为；真实模型参考样本仍为 0。

## 常见词的意思

| 文档中的词 | 实际指什么 |
| --- | --- |
| 渠道 / Provider | 你在 Magpie 里配置的供应商连接 |
| 探针 | 插件专门发出的一次测试请求 |
| 行为指纹 | 从回答里算出的、用来比较模型的特征 |
| 参考库 / 基准库 | 来源、采集条件和版本有记录的对照样本 |
| 校准 | 用独立样本确定“多像才算匹配”、校正概率；最终测试再换一批样本检查误报 |
| PoC | 先做小实验，确认某项功能确实能跑通 |
| P0–P6 | 开发阶段的编号，对应执行计划中的七个阶段 |
